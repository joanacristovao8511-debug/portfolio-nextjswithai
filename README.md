# portfolio project

## Cloudflare Pages deployment

This project is a static React app and can be deployed on Cloudflare Pages.

### Build settings

- Build command: `npm run build`
- Output directory: `build`

### Deployment steps

1. Open Cloudflare Pages.
2. Create a new project and connect the GitHub repository.
3. Use the settings above.
4. Deploy.

### Notes

- The project was verified to build successfully with `npm run build`.
- The generated static site is output to the `build` folder.
- The Cloudflare CLI login can time out in some terminal environments, so the dashboard deployment flow is the most reliable option.
